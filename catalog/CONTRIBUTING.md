# Contributing to the catalog

Open a GitHub issue with the proposed entry, who publishes it, and how you would use it. Maintainers make catalog changes. The workflow closes pull requests from forks and directs the author to issues.

For apps, link the publisher’s MCP documentation and logo guidance. Keep credentials and customer data out of every catalog file. After editing an entry, run `bun build.ts` and commit the refreshed `index.json` with the entry.
