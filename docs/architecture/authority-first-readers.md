The release writes only deployed envelopes or additive v1 fields at these boundaries. The audit predecessor fixture runs its original link against current settings stdin and the current repair record, then opens the resulting unmarked record again with the new link. A predecessor that ignored an unknown marker can still reinterpret old-looking incompatible bytes if started against them. Before emitting any incompatible on-disk version, require a rollback barrier that prevents such binaries from opening the record, or retain that version in a separate location through rollback. Choose that contract alongside the upgrade step. This patch exercises refusal and byte retention by the new reader and does not establish arbitrary future-record retention by a pre-gate binary.
